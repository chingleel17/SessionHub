# Proposal

## Why

SessionHub 已能取得 Codex／ChatGPT（OpenAI）重置券的數量、到期時間並手動使用，但使用者仍可能忘記使用而讓券到期。新增每日到期提醒及到期前自動使用，讓使用者可在設定頁分別控制，降低錯過使用期限的機會。

## What Changes

- 在設定頁的用量監控區新增「Codex 重置券」設定，提醒與自動使用為兩個獨立開關，預設皆關閉。
- 提醒預設於每天本地時間 `09:00` 檢查，可調整每日提醒時間，以及提前提醒天數（`0–30` 天，預設 `0`，表示當天到期）。同一帳號一天最多一則到期彙總提醒。
- 通知顯示今天到期的可用張數；設定提前提醒時，另顯示未來範圍內的到期張數。只有自動使用已啟用且可執行時，才說明「將在到期前 1 分鐘嘗試自動使用」。
- 自動使用固定以到期前 `60` 秒為觸發點，執行前重新查詢帳號與重置券，與手動使用共用消耗協調及結果更新，避免重複請求。
- 納入多張券、無到期時間、失效憑證、帳號切換、API 無法指定券、請求結果不明與重啟去重的處理。
- 背景執行由 Rust 負責，在主視窗隱藏至系統匣時仍有效；啟動或喚醒後補查當天提醒及尚未到期的自動使用工作。已過期的券不補用。
- 首版不提供獨立「指定日期／時間使用」排程介面；到期前自動使用即為本次需要的排程能力。不新增 Windows 工作排程器、喚醒電腦或退出程式後執行的機制。

## Capabilities

### New Capabilities

- `codex-reset-credit-automation`: 定義重置券到期彙總、每日通知、到期前自動使用、背景生命週期與持久化去重。

### Modified Capabilities

- `app-settings`: 新增重置券提醒與自動使用欄位、預設值、驗證、獨立開關及設定頁說明。
- `provider-quota-monitoring`: 保留手動使用確認流程，讓手動與自動消耗共用帳號範圍、並行協調與結果刷新。

## Impact

- 前端：`src/components/SettingsView.tsx`、`src/App.tsx`、`src/types/index.ts`、既有 zh-TW／en-US 翻譯；沿用現有設定儲存與通知呈現方式。
- 後端：`src-tauri/src/types/settings.rs`、`settings.rs`、`quota/codex.rs`、`quota/mod.rs`、`commands/quota.rs`、`app_setup.rs`；新增獨立的重置券背景協調模組與 SQLite 執行紀錄。
- API：沿用既有 reset-credits 查詢／consume 端點，不假定支援指定券或服務端最早到期優先。存在不同效期的券且無法確認選券順序時，自動使用暫停並說明原因。
- 通知：沿用 Tauri 2 notification plugin 與 SessionHub Windows 通知識別；安裝版進行原生通知驗收。
- 舊設定可直接載入；新增設定預設關閉，不改變現有使用者的手動操作。應用程式退出、電腦關機／休眠、離線或服務端拒絕時，無法保證使用成功，設定說明與通知須準確反映此執行範圍。
